# Banco Hospitalar

Projeto de banco de dados desenvolvido para simular a estrutura de um sistema hospitalar.

O objetivo é representar entidades importantes de um ambiente hospitalar, como pacientes, médicos, consultas, exames, medicamentos, departamentos e agendamentos.

## Tecnologias utilizadas

- SQL
- MySQL/PostgreSQL
- Modelagem de Banco de Dados

## Funcionalidades do banco

- Cadastro de pacientes
- Cadastro de médicos e enfermeiros
- Registro de consultas
- Controle de exames
- Controle de medicamentos
- Organização por departamentos
- Agendamentos hospitalares

## Arquivo principal

O arquivo `banco_hospitalV3.sql` contém a criação das tabelas e os dados utilizados para teste.

## Objetivo do projeto

Este projeto foi criado com fins acadêmicos para praticar modelagem, criação e manipulação de banco de dados em um cenário hospitalar.
